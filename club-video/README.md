# EDEN BEAUTY CLUB – סרטון הסבר (25 שניות)

אנימציה ב־HTML/CSS תלת־ממדי + GSAP, מיוצאת ל־MP4 עם Playwright (צילום פריים־פריים) ו־ffmpeg.
לא נדרש Blender – כל התלת־ממד (כרטיס מסתובב, טלפון, מטבע, ארנק) נעשה ב־CSS 3D.

## קבצים

| קובץ | מה |
| --- | --- |
| `index.html` | הסרטון עצמו (טיימליין GSAP אחד, 6 סצנות) |
| `render.mjs` | ייצוא ל־MP4 |
| `out/eden-beauty-club-9x16-preview.mp4` | אינסטגרם / רילס / סטורי – 1080×1920 |
| `out/eden-beauty-club-16x9-preview.mp4` | אתר / יוטיוב – 1920×1080 |
| `shopify/sections/eden-club-video.liquid` | אזור באתר: סרטון + הצטרפות (לא הועלה לחנות) |

## ייצוא

```bash
npm install
node render.mjs                        # שתי הגרסאות, עם תווית "הדמיה · המועדון יושק בקרוב"
node render.mjs --final                # בלי התווית – רק אחרי שהמועדון נבדק ופעיל
node render.mjs --voice voice.mp3      # עם קריינות
node render.mjs --voice voice.mp3 --music music.mp3
```

צפייה בזמן אמת בדפדפן: `index.html?format=vertical&play=1`.

## לפני פרסום

הסרטון מתאר את המועדון כפי שהוגדר: 3% מהסכום ששולם על המוצרים, בלי משלוח, נשמר כיתרת קרדיט
ונממש בקופה כשהלקוחה מחוברת. כל עוד לא אומתה צבירה בפועל (Flow + הזמנת בדיקה) – להשתמש בגרסת ה־preview בלבד.

הלוגו בסוף הוא כיתוב "EDEN · BEAUTY SHOP" – קובץ הלוגו המקורי לא היה נגיש מסביבת העבודה.
