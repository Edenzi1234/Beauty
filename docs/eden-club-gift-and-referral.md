# EDEN BEAUTY CLUB – מתנה בקנייה מ־1,000 ₪ ו"חברה מביאה חברה" (ניהול)

## מתנת מועדון בקנייה מ־1,000 ₪

**איך זה עובד**
- בעגלה (הסל הצדדי) חברת מועדון מחוברת רואה מד "עוד X ₪ ומחכה לך מתנה". מ־1,000 ₪ נפתח אזור בחירה עם 4 המתנות.
- בחירה אחת בלבד. KOYO – בוחרים 2 גוונים מהמלאי; טיפסים BUBA – בוחרים צורה. אפשר להחליף עד התשלום.
- אם העגלה יורדת מתחת ל־1,000 ₪ (אחרי הנחות, בלי משלוח) – המתנה יורדת מהעגלה לבד.
- מוצג רק מה שיש במלאי.
- המחיר 0 ₪ נקבע ע״י Shopify בהנחה האוטומטית – לא ע״י האתר.

**ניהול**
| מה | איפה |
| --- | --- |
| המתנות (הוספה / הסרה / שינוי מוצרים, שם, כמות, סדר) | Content → Metaobjects → **מתנת מועדון EDEN** |
| הפעלה / כיבוי של אזור המתנה | Settings → Custom data → Shop → **מתנת מועדון – פעילה** |
| סכום מזכה | Settings → Custom data → Shop → **מתנת מועדון – סכום מזכה (₪)** + אותו סכום בהנחה |
| ההנחה עצמה (בדיקת הזכאות בצד השרת) | Discounts → **EDEN CLUB – מתנה בקנייה מ־1,000 ₪** |
| המוצרים שההנחה נותנת בחינם | Collections → **EDEN CLUB – מוצרי מתנה (לא להציג)** |

**בדיקה בצד השרת (Shopify)** – ההנחה האוטומטית:
- רק לקבוצה "חברות מועדון EDEN" (תגית EDEN_CLUB_MEMBER, חייבת להיות מחוברת בקופה).
- רק כשסכום המוצרים ≥ 1,000 ₪.
- עד 2 יחידות מקולקציית מוצרי המתנה ב־100% הנחה, פעם אחת בהזמנה.
- משתלבת עם קודי הנחה, משלוח ו־3%.

**מגבלות שחשוב לדעת**
- Shopify בודק את ה־1,000 ₪ לפי מחיר המוצרים. אם קוד הנחה מוריד את ההזמנה מתחת ל־1,000 ₪ – העגלה מסירה את המתנה, אבל קוד שהוזן רק בקופה לא מוכר לעגלה. מומלץ לעבור על הזמנות עם מתנה מעל לפני משלוח (Orders → חיפוש "_eden_gift").
- "אחת מתוך 4" נאכף בעגלה; Shopify עצמו מגביל ל־2 יחידות בחינם בהזמנה.
- לשינוי קבוע מלא בצד השרת (חישוב אחרי הנחות + אפשרות אחת בדיוק) צריך Shopify Function – אפליקציה ייעודית.

**הפעלה (בסדר הזה)**
1. לפרסם את התבנית "EDEN Club – תיקון נוסח (לא לפרסם עד שמוכן)".
2. Discounts → EDEN CLUB – מתנה בקנייה מ־1,000 ₪ → Active dates → Start date = היום → Save.

## חברה מביאה חברה

- עמוד: /pages/eden-club-members (בתחתית האתר: "חברה מביאה חברה").
- הגדרות: Settings → Custom data → Shop – סכום (20), מינימום (500), ימי המתנה (0 = מיד אחרי ההזמנה), פעיל.
- הקישור האישי: /?ref=<מזהה הלקוחה>. ההפניה נשמרת בעגלה (eden_ref → מופיע בהזמנה) ובתגית EDEN_REF_BY_<מזהה> בהצטרפות.
- **הזיכוי לארנק (20 ₪ לכל אחת) נעשה ב־Flow – עדיין לא הוגדר.** תהליך: Order paid → אם יש eden_ref / תגית EDEN_REF_BY_ → לקוחה חדשה (הזמנה ראשונה) → סכום אחרי הנחות ללא משלוח ≥ 500 → מפנה ≠ לקוחה, מפנה עם EDEN_CLUB_MEMBER, בלי תגית EDEN_REFERRAL_CREDITED → storeCreditAccountCredit לשתיהן → תגית EDEN_REFERRAL_CREDITED + עדכון המונים אצל המפנה.
